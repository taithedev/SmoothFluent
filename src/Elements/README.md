# SmoothFluent Elements

SmoothFluent elements are organized around the same developer-facing categories as Fluent-modded.

Supported API surface includes Button, Toggle, Slider, Input, Dropdown, MultiDropdown, Colorpicker, Keybind, Paragraph, Code, Divider, Space, Image, Video, Audio, Group, Social, Discord, Viewport, Label, and Text.

The implementation is maintained independently.
