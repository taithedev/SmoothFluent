# Contributing

Thanks for helping improve SmoothFluent.

Before changing code:
- Read docs/API.md.
- Keep public APIs documented.
- Keep examples working.
- Add a changelog entry for public behavior changes.
- Avoid undocumented breaking changes.

## Pull requests

Describe what changed, why it changed, API changes, and how it was tested.

## Testing

Test affected features in Roblox Studio or the target runtime before calling an API stable.
