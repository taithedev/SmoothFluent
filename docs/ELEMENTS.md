# Elements

SmoothFluent keeps the Fluent-style element vocabulary.

## Common elements

- AddButton
- AddToggle
- AddSlider
- AddInput
- AddDropdown
- AddMultiDropdown
- AddColorpicker
- AddKeybind
- AddParagraph
- AddCode
- AddDivider
- AddSpace
- AddLabel
- AddText
- AddImage
- AddVideo
- AddAudio
- AddGroup
- AddSocial
- AddDiscord
- AddViewport

Every element is designed to work with the shared theme and search systems.

## Options

Interactive elements expose GetValue and SetValue where applicable and are registered through Fluent.Options.

Flags are stored through Fluent.Flags.
