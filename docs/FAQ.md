# FAQ

## Is SmoothFluent Fluent-modded?

It is an independent Roblox UI framework designed around a familiar Fluent-style API and workflow.

## Does it support themes?

Yes. The core includes a large preset catalog and custom themes.

## Can I use Rojo?

Yes. The repository includes default.project.json and a package build script.
