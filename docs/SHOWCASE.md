# Showcase Checklist

The Showcase example should demonstrate the same kinds of UI developers expect from a Fluent-style library:

1. Main tab
2. Settings tab
3. Visual tab
4. Components tab
5. Notifications
6. Dialogs
7. Theme switching
8. Sliders and toggles
9. Dropdowns
10. Keybinds
11. Media
12. Groups
13. Search

Use the showcase as the first Studio smoke test after importing SmoothFluent.
