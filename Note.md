# SmoothFluent Notes

SmoothFluent is being developed as a full UI framework rather than a small widget collection.

Goals:
1. Keep a familiar Fluent-style developer experience.
2. Keep the implementation modular.
3. Provide many polished themes.
4. Make examples easy to copy and modify.
5. Keep documentation close to the source.
6. Preserve credits for projects that inspired the API and ecosystem.

## Compatibility

The goal is API familiarity, not a promise that every undocumented internal behavior from another library is identical.

## Releases

Public updates should receive a version bump and changelog entry.
